SMART FEEDER IoT — WIRELESS CLOUD SYSTEM

Proyek Rekayasa Teknologi • Kelas XI-7 • SMAN 14 Surabaya

Sistem Smart Feeder IoT Wireless dikembangkan oleh Kelompok Rekayasa (Kelas XI-7, SMAN 14 Surabaya) untuk mengotomatisasi pemberian pakan ikan dengan durasi presisi 3 detik melalui kendali cloud secara real-time maupun akses lokal Captive Portal.

> ARSITEKTUR SISTEM: NodeMCU ESP8266 + Relay 1-Channel (Auto-Off 3 Detik) + LCD Matrix 16x2 I2C + Firebase Cloud.
